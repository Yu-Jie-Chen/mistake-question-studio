# 公式展示：源文、渲染与验收

有公式时读取本页。错题卡、错题库与教学资料可能使用不同渲染器；某处正常不能证明其他位置也正常。

## 写入源文

在 `text/question.json` 的 Markdown 字段中保留完整 LaTeX，以 `$...$` 或 `$$...$$` 包围。通过 JSON 序列化写入，避免反斜杠成为转义字符；读取 JSON 后，实际公式应只有一个命令反斜杠。

| 内容 | 推荐源文 | 检查点 |
|---|---|---|
| 实数、正整数 | `\mathbb{R}`、`\mathbb{N}^{*}` | 黑板粗体；不可出现 `mathbbR` 文本 |
| 集合 | `\{x\mid -1<x<2\}` | 集合左右花括号与竖线都保留 |
| 函数 | `f(x)`、`f(n+1)<f(-n)` | 普通数学斜体；不另换成花体或 Unicode 艺术字 |
| 根式、分数 | `\sqrt{x^{2}}`、`\sqrt[3]{2}`、`\frac{1}{2}` | 被开方数、根指数、分子分母范围明确 |
| 向量 | `\vec{v}_{1}`、`\overrightarrow{AB}` | 确有箭头；不得为适配显示改成 `\bar{v}` |

多字符上、下标使用花括号，例如 `x^{n+1}`。不要依赖 `\frac12`、`\mathbb R` 等简写在不同引擎中碰巧可用。根号、分数、括号、箭头和集合竖线承载数学意义，不能用 CSS 叠字或手绘横线替代源文结构。

## 按目标选择渲染

| 目标 | 处理方式 | 不能据此推断的内容 |
|---|---|---|
| Markdown 卡片 | 默认 `run.py finish` 生成公式 PNG 与 `card.latex.md` 源文副本 | PNG 正常不证明错题库的 LaTeX 解析正常 |
| 工作台错题详情 | 从 JSON 读取 LaTeX，使用工作台自身渲染器 | 与 Matplotlib、KaTeX、MathJax 的支持集不等价 |
| HTML 教学资料 | `build_card_html.py` 内嵌 PNG，离线打开；也可用已验证的静态 MathML | 预览容器可能禁用脚本，依赖运行时 JS 的网页不是自包含交付 |
| Word（明确要求时） | 原生公式或内嵌公式图，实际打开/渲染核对 | HTML 截图不能代替 Word 验收 |

生成时使用 `python scripts/run.py finish <workdir> --html`。直接调用 builder 时加 `--formula-mode both --strict`。`finish` 会阻断渲染失败；非零退出后产生的文件仍是失败草稿，不能因为文件存在就交付。仅在已验证目标查看器支持全部命令时使用 `--formula-mode latex`。不使用 `--allow-raw-math` 绕过 HTML 检查来交付。

Matplotlib MathText 只支持 LaTeX 子集。未知命令应查明是源文拼写问题还是渲染器缺失：前者修源文，后者选择支持该语义的渲染器或修复渲染层，并重新核对。不要删除反斜杠、箭头或改变题意来消除报错。

若已连接工作台、且可访问同版本源码，归档前使用该版本检查器（存在时）：

```sh
node <workbench_root>/tools/check_formula_display.js <workdir>/text/question.json
```

检查器也可检查 `card.latex.md` 或递归目录中的 `question.json`。未知命令和不平衡公式须修复。检查器缺失时不要求安装整个工作台；保留严格构建和目标页面检查，并说明未做该兼容性预检。检查返回 `ok` 仅证明其检查范围内的语法支持，不能证明字形、间距、裁切或数学答案正确。

## 视觉验收与回归

逐题核对源图中的表达式和生成结果；同批相同公式结构可复用一次字形验证，但每题仍检查内容和溢出。以下结构本批出现时均需覆盖：集合与黑板粗体、函数末尾括号、多层根式/分式、带上下标的向量、长行公式。

1. 在实际交付尺寸打开卡片与 HTML；检查右端括号完整、根号横线连续且覆盖范围正确、分数和上下标没有交叠、向量有箭头、变量与数字字形一致。
2. 已归档时，打开回执对应题目的题干、选项、答案和解析，再打开对应教学资料预览；检查不存在 `mathbb`、`xmid`、未知命令、丢失图片或横向裁切。对照同一题，避免检查另一份旧附件。
3. 在 `review.md` 记录实际检查的目标、题目/资料 ID 或本地文件、代表公式、结果和截图路径（如有）。归档回执只证明存储，截图只证明所见范围；不能据此声称全部公式永远正确。
4. 无法打开目标页面时，区分“本地生成/离线检查通过”和“目标展示待核验”，保留草稿状态，如实报告限制。不要把待核验项填成已通过。

修复时以 JSON 为源重建受影响成品。修复渲染器后使旧公式图片缓存失效；不要仅手改生成的 HTML。脚本回归可运行 `python scripts/test_display_quality.py`；它验证构建失败处理、图片边界、离线附件和索引路径，不能替代上述视觉核对。
